Features

Built different.

IsotopeOS ships with everything you need — your choice at first boot, no bloat, no forced installs.

Modular installs

Choose exactly what gets installed at first boot — Gaming, Corporate, Education, or Minimal. Your machine, your rules.

Parental controls

Built in across all editions. Basic for home, advanced for Pro and Business, full school-grade controls for EDU.

Actinium browser

Velox's own browser ships with every edition — fast, private, and deeply integrated with IsotopeOS.

Universal app support

.vx native apps, .exe via Wine, .dmg via Darling, .deb and AppImage — run software from any platform.

Gaming ready

Sober for Roblox, Steam, Lutris, and MangoHud pre-configured in the Gaming tier — one click setup.

Python pre-installed

Python ships on every edition out of the box. No setup, no version conflicts — just open a terminal and go.

Roadmap

Where we're headed.

IsotopeOS is in active development. Here's the plan.

Phase 1

Foundation

Ubuntu Server base, strip bloat, build system setup, bootable ISO.

Phase 2

Desktop Environment

Window manager in C, panel and taskbar in GTK, app launcher and file manager in Python.

Phase 3

First Boot Wizard

App tier selection, language and region, user account setup, driver detection.

Phase 4

Polish & Beta Release

Branding, themes, performance tuning, documentation, and public beta launch.
